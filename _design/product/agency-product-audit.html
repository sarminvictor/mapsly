The five blockers · the five wins

// rolled up from the 15 scenarios
Top 5 gaps — what blocks the sale at $99
1
Configurable filter values. Every numeric filter is a hardcoded chip ("Reviews ≥ 100", "Lighthouse < 60"). No slider, no number input, no comparator picker.
Fix: range inputs + comparators on every numeric signal · 1-day build · biggest UX win available
2
Custom list builder. "+ New list" exists but has no flow. No naming, no scheduling, no owner assignment, no save-from-search modal.
Fix: list-creation modal that captures name + filter set + refresh cadence + owner
3
Lead status / contact tracking. Tom emails a prospect → 24h later they show up as "new" again. He can't mark contacted/passed/replied/follow-up.
Fix: 5-state status field per lead + manual setter + auto-hide contacted ≤ 30d from list view
4
"Mark as client" / clone-list / global biz-search. Three small affordances that together kill 30% of friction.
Fix: 3 small UI additions — each < 4h work
5
One-pager editor. Currently the one-pager is a static auto-fill. Tom wants to swap findings, edit projected impact, drop the line about Sisu if irrelevant.
Fix: inline-edit on each finding block + drag-to-reorder + custom impact numbers
Top 5 wins — what's actually compelling
1
Signal vocabulary is unique. 60+ filters, half of them not available in Apollo, ZoomInfo, Lemlist, or any other tool the agency uses. "Brand hijack detected" alone is a wedge.
Strategic: this is the moat. No one else qualifies prospects on Lighthouse scores + ad-lane gaps + reply rate.
2
Prospect deep-dive is genuinely useful. The four pitch-wedge talking points + evidence footers means Tom can walk into a meeting prepared without external research.
Time saved: ~20 min per prospect of manual cross-referencing
3
One-pager output is professional. Print-ready, single page, branded, with evidence trails. Agencies pay $50–200 per such artifact when they outsource creation.
Direct ROI claim: "generate 5 of these per week = $1k/mo of designer time saved"
4
Service-template quick-start. 8 one-click templates ("Website rebuild", "Meta ads campaign", "Local SEO", etc.) let a new user get to value in < 60 seconds. Great onboarding hook.
Adoption: removes the "blank canvas" problem most B2B tools have
5
Daily auto-refresh. "23 new leads overnight" is the dopamine hit that gets Tom logging in every morning. The system delivers fresh ammunition.
Retention: this is the habit-forming loop · daily check-in > weekly check-in for stickiness

Pricing reality — is this a $99 product?

// the question you asked
Short answer: yes at $99, no at $249. The current build delivers ~$300–600/mo of value for a solo or 2-person agency, but only if the agency uses Mapsly daily as the prospecting engine. A $99/mo price point creates the gravity to commit; $249 makes them shop alternatives. The premium tier should unlock the operations layer (status tracking, team scoping, analytics) — that's where the next $150/mo of value lives.

// Audit method: walked 15 scenarios end-to-end against the current build (agency/ + product/), recorded behavior, scored on "can Tom complete it without leaving Mapsly + without complaining". Scores are deliberately strict — anything friction-heavy lost a point even if technically possible. The 6.0 weighted score reflects strong discovery + research + freshness offset by missing customization + ops. Three blockers (#1, #2, #3) gating $99 launch readiness. None gating $49 hook tier. Verdict: ship the Solo + Growth tiers within 2 weeks after closing the three blockers, hold $249 until the ops layer ships.
