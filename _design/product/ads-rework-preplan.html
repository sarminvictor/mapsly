From a broken "competitor creative gallery" to a Google Ads Market-Intelligence surface for Maria — built on DataForSEO, aligned to the /search pipeline pattern.

0TL;DR & verdict

The current /ads page is architecturally clean but functionally dead — all three of its data inputs are broken or stubbed, so it shows nothing real for any business. The fix is not "repair the pipes"; it's a strategic pivot in what the page is for.

Three confirmed breakages (live-tested):
  • Meta Ad Library token is invalid — the value in .env.local is 32 chars and doesn't start with EAA; it is not a Graph token. Every Meta call returns 400 · Invalid OAuth access token. The daily ad-library-diff cron has therefore never returned data.
  • Google Ads Transparency is a stub — daily/google-ads-transparency only marks 30-day-old rows inactive. No adapter exists (TODO C.4b). Google ad data is never collected.
  • Keyword lanes are non-functional — the Meta cron never writes matchedKeyword, so every ad falls into the __unmatched__ bucket → flagged off-keyword → the entire "14 keyword lanes" concept renders as noise.
The opportunity (live-tested): the actionable ads product for a med-spa owner is not a gallery of competitors' Facebook images — it's Google Ads market intelligence: what each keyword costs to advertise on, who is bidding, where the cheap high-intent openings are, and "what would $X/mo get me?". DataForSEO delivers all of this cleanly, cheaply (~$0.08–0.12/business/refresh on the Standard queue), and with zero scraping/ban risk. This is exactly the model Boxly already ships.

The verdict in one line

Rebuild /ads as "Ads & market intelligence" powered by DataForSEO (keyword costs + Google Ads Transparency + paid-SERP), wired through the same cron→dispatcher→worker→DB pattern as /search. Treat Meta as out-of-scope for v1 (broken + API doesn't expose commercial ads outside the EU). Add a Google-Transparency competitor-creative panel where coverage exists.
