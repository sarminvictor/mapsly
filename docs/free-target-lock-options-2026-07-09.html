⭐ Hybrid · OA + OC now, OB as phase 2 recommended

All three judges converge here. Phase 1 (one session): unlock the picker (OA), swap 🔒 for the "Preview" chip, and give the footer the dual CTA (OC-lite — honest "search all mapped markets with these signals" copy; upgrade CTA stays visually co-equal). Ship the server un-dark + locale-link fix in the same commit. This is Apollo's explore-free model + Canva's free-path redirect at $0 marginal vendor cost, fully consistent with the FT-2 entitlement plan.

Why the evidence points this way

  • "Tease, don't hide" is the consistent 2023–26 finding. Freemium median free→paid is 8%; the bottom quartile (<2.5%) vs top (10–15%) spread is explained by prompt placement and value visibility, not the model. (Growth Unhinged conversion report; Userpilot benchmarks)
  • Named analogs per option: Apollo — browse the whole database free, pay at reveal (OA/OB). Canva — premium element blocked → "replace with a free one" (OC). Typeform/Ahrefs/LinkedIn — real data up to a visible cap (OB). Slack — your own history gated, loss aversion (why naming their markets in the CTA matters).
  • Don't blur aggregates. Tom's stated purchase driver is "I trust the data"; blur/teaser paywalls that obscure rather than prove value are flagged as dark-pattern-adjacent. Real counts, honest "not yet mapped" dashes.
  • Reverse-trial evidence is for full temporary access, not one-taste samples — OD borrows the name without the mechanism.
Recommendation. Ship the Hybrid phase 1: OA's unlocked picker + preview chip + OC-lite's dual CTA, plus the one-line server un-dark of market_locked and the locale-link fix — one session, ~100–130 LOC, $0 new cost exposure, strictly better bounded than today. Queue OB as phase 2 behind two prerequisites: the PreviewStep auto-run guard, and enough index coverage that the tease shows numbers instead of dashes. Reject OD.
